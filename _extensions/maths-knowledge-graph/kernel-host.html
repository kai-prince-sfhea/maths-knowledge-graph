Optional mathematical proof kernel host

This original bridge must be served from the same origin as the separately supplied Argumentation Sandbox distribution. Its Coq 8.20.1 / jsCoq 1.99.2 runtime and matching libraries retain their own licences and are not included in this extension.

The bridge loads that runtime only for an explicitly requested, source-bound generated certificate. Kernel acceptance does not establish fidelity to mathematical prose. Compatible clients can separately request fixed global-assumptions and typing-flags inspection. Unknown or unsupported output remains unknown; declared quantified premises remain conditions of the generated theorem.
